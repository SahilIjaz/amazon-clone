# Agent logs

This directory captures the AI-agent session used to build this project: the prompts given to the coding agent
(Claude Code) and a faithful summary of each response and the actions it took, in chronological order.

- `2026-09-13-build.md`: the build session for the Amazon rebuild (research, decisions, implementation, testing, deployment).

Logs are committed progressively during the build rather than in one lump at the end.
