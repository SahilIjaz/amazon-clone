## Response 2, continued: persistence on Vercel
- Problem found by the live end-to-end run: without a hosted database each serverless instance had its own /tmp SQLite file, so a cart added on one instance was invisible on the next (accounts and orders would vanish the same way). The Turso marketplace integration needs the account owner to accept terms in the browser, which the agent cannot do.
- Fix that needs no third-party sign-up: created a first-party Vercel Blob store and connected it to the project. `src/lib/db.ts` now keeps SQLite in rollback-journal mode, mirrors the .db file to the blob after every write and re-downloads it when another instance has written since (last writer wins; fine for a demo store). Turso still takes precedence when `TURSO_DATABASE_URL` is set.
- Second visual pass applied: buy-box column narrowed to match the real page, hero gradient sampled from the real banner (#a938fa → #132563), deals page category pill row, richer empty-cart illustration.
